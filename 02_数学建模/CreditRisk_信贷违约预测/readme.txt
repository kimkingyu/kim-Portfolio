# 个人信贷违约风险评估与预测系统

## 1. 项目背景
个人信贷违约风险预测是金融风控领域的核心决策课题。本项目基于借款人多维度财务与历史信用记录数据，构建了完整的端到端信贷违约预测与机器学习可解释性分析体系。

## 2. 核心技术流程
- **探索性数据分析 (EDA)**：分析各特征分布、缺失值现状及目标违约样本不平衡特征。
- **数据预处理**：缺失值插补、有序与无序类别特征编码（Label Encoding / One-Hot Encoding）、连续特征标准化。
- **不平衡样本处理**：采用 SMOTE 过采样平衡违约与履约样本分布。
- **多模型对比与超参数优化**：构建逻辑回归、支持向量机 (SVM)、朴素贝叶斯、随机森林、XGBoost 与 LightGBM 模型，并基于网格搜索 (GridSearchCV) 执行精细化超参数调优。
- **模型可解释性分析 (XAI)**：基于 SHAP 理论与偏依赖图 (PDP) 深入分析全局特征重要性、个体样本贡献度与特征交互效应，为信贷风控提供透明化决策依据。
