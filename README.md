# kim-Portfolio

本科期间工程实践与算法建模项目归档。

## 目录结构

- **01_毕业设计**：基于视觉手势追踪的机器人遥操作系统（ROS + 计算机视觉 + 机械臂控制）
- **02_数学建模**：数据分析与机器学习算法项目（按数据集分类）
  - `CWRU_轴承故障诊断`：凯斯西储大学轴承振动信号故障诊断
  - `CreditRisk_信贷违约预测`：信贷违约风险评估与 SHAP 分析
  - `BikeSharing_单车需求预测`：Kaggle 共享单车需求回归预测
  - `CIFAR10_图像分类与对比学习`：CNN / ResNet18 图像分类与对比学习
  - `CarEvaluation_汽车评估决策分类`：UCI 汽车评估多属性决策分类
  - `Iris_鸢尾花分类与不平衡学习`：数据增强与多分类器对比
  - `MultiDataset_聚类与降维`：K-Means 聚类与 PCA 降维
  - `OpenCV_计算机视觉实验`：OpenCV 基础图像处理实验
- **03_单片机**：51 单片机开发工程（PWM 呼吸灯、外设例程）
- **04_无碳小车**：无碳循迹小车 SolidWorks 3D 装配体与工程图
- **07_CAD机械作品**：一级圆柱齿轮减速器 CAD 图纸与轴系分析
